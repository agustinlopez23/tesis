# Tesis — Marketplace hiperlocal

Prototipo para comercios de Córdoba. Backend ASP.NET Core en capas y frontend
Next.js con TypeScript. Además de la conectividad inicial, el prototipo ya permite
registrar responsables, iniciar y revocar sesiones y administrar negocios propios
con ubicación PostGIS. El panel web de este recorrido también está implementado.
