# Preparar el experimento y la integración

Resultado: protocolo revisable con criterios numéricos propuestos, separación de
datos, rúbrica humana, plantillas y contrato de candidatos/paginación. Alcance de
este incremento: documentación y archivos de intercambio, sin ejecución final.

Depende de piloto y ablaciones existentes. Fuera de alcance: inventar juicios,
declarar criterios acordados sin respuesta, activar ranking, catálogo y despliegue.
Éxito: límites inequívocos, datos faltantes explícitos, plantillas consistentes,
brechas contra código actual y siguientes pasos implementables.
