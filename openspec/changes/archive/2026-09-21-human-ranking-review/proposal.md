# Cargar juicios humanos sin inventar evidencia

Resultado: registrar criterios principales acordados y validar las hojas humanas
contra consultas/candidatos declarados, conservando faltantes y desacuerdos.
Incluye CLI de importación CSV, reporte JSON, hashes y pruebas. No genera grados,
no certifica que un evaluador sea humano ni ejecuta el experimento final.

Éxito: entradas inválidas rechazadas; incompletas identificadas; juicios finales
exportados solo con cobertura completa. Dataset semántico y personas aún pendientes.
